## Короткий опис рішень
 
- **Задача 1.** Рядки складаються у динамічний список лише додаванням у кінець
  (`append`), розворот виконується один раз наприкінці (`[::-1]`). Вставка на
  початок (`insert(0, ...)`) ніде не використовується.
- **Задача 2.** Підсумки зберігаються в масиві фіксованого розміру (12
  елементів). Номер місяця напряму слугує індексом (`month - 1`), пошуку
  перебором немає.
- **Задача 3.** Останні N=5 подій зберігаються в кільцевому буфері — масиві
  фіксованого розміру з лічильником комірки для наступного запису
  (`_next_slot`), що йде по колу через `% capacity`. Найстаріша подія ніколи
  не видаляється зсувом з початку колекції — вона просто перезаписується.
